Informatikë - Fillestar - M2 — Kushte if/else

if kontrollon një kusht True/False else ekzekutohet kur kushti është False elif shton kushte të tjera Hyrja (indentimi) përcakton bllokun and/or/not kombinojnë kushte

Kod / formulë

x = 10
if x > 5 and x < 8:
    print('mes')
elif x >= 8:
    print('lart')   # ky
else:
    print('ulët')
