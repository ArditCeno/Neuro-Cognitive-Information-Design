  • A variable holds one value: x = 5
  • Base types: int, float, str, bool
  • A variable name does not start with a digit
  • '=' is assignment, '==' is comparison
  • type(x) returns the type of the value
x = 5
y = x
x = 7
print(y)   # 5
print(type(3.14))  # <class 'float'>
