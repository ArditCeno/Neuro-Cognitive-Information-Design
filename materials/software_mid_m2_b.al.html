Informatikë - Mid - M2 — Filtrim listash

List comprehension: [x for x in a if kusht] filter() zgjedh elemente sipas kushtit sorted() kthen listë të renditur sum(), min(), max() mbi lista Slicing: a[1:3] jep elementet 1 dhe 2

Kod / formulë

a = [1,2,3,4,5,6]
pare = [x for x in a if x % 2 == 0]
print(pare)  # [2,4,6]
