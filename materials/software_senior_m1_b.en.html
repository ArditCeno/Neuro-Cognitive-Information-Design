Binary search is O(log n) and needs a sorted list Two nested loops over n give O(n^2) O(n log n) beats O(n^2) for large n 'x in list' is O(n) Algorithms differ in complexity, not just speed

def binary_search(a, t):
    lo, hi = 0, len(a)-1
    while lo <= hi:
        mid = (lo+hi)//2
        if a[mid] == t: return mid
        if a[mid] < t: lo = mid+1
        else: hi = mid-1
    return -1
