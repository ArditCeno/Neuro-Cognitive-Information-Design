Kontrolli i hyrjes — Guard Clauses

I njëjti funksion, i rishkruar me guard clauses: kushtet e dështimit kontrollohen herët dhe funksioni kthehet menjëherë, duke mbajtur rrjedhën lineare.

function checkAccess(user) {
  if (!user) return "deny";
  if (!user.active) return "deny";
  if (!user.paid) return "deny";
  return "access";
}

Çdo kusht dështimi trajtohet veçmas dhe mbyll funksionin. Nuk ka else të mbivendosur, kështu që syri ndjek një linjë të drejtë.

  • Nuk ka thellim (nesting).
  • Çdo rresht ka një qëllim të vetëm.
  • Rruga e suksesit shihet qartë në fund.
