Kontrolli i hyrjes — checkAccess()

Funksioni i mëposhtëm përcakton nëse një përdorues ka të drejtë të hyjë në panelin e administratorit. Kushtet kontrollojnë ekzistencën, statusin aktiv dhe statusin e pagesës.

function checkAccess(user) {
  if (user) {
    if (user.active) {
      if (user.paid) {
        return "access";
      }
      return "deny";
    }
    return "deny";
  }
  return "deny";
}

Funksioni kthen gjithmonë një varg: "access" ose "deny". Vini re se të gjitha kushtet kontrollohen me radhë brenda njëra-tjetrës.

Blloku i brendshëm if kontrollon njëkohësisht user.active dhe user.paid. Hyrja jepet vetëm kur të tre kushtet janë të vërteta: përdoruesi ekziston, është aktiv dhe ka paguar.

Nëse përdoruesi nuk është aktiv, funksioni kthen menjëherë "deny", pavarësisht statusit të pagesës.
