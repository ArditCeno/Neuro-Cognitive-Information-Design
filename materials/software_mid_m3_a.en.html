Software - mid - M3 - Kombinim: funksione + lista + kushte

  • d['a'] reads the value of key 'a'
  • d.get('k', 0) returns 0 if 'k' is missing
  • max([]) raises ValueError
  • enumerate() yields (index, value) pairs
  • A dict counts frequencies well
def frekuenca(lst):
    d = {}
    for x in lst:
        d[x] = d.get(x, 0) + 1
    return d
print(frekuenca([1,2,2,3,3,3]))  # {1:1,2:2,3:3}
