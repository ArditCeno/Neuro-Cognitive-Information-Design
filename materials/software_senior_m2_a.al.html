Informatikë - Senior - M2 — Struktura të dhënash

  • Stack: LIFO (push/pop)
  • Queue: FIFO
  • Set: pa dublikatë, kërkim mesatar O(1)
  • Dict/hash table: akses mesatar O(1)
  • Pema binare: secili nyje ka maksimum 2 fëmijë

Kod / formulë

stack = []
stack.append(1); stack.append(2)
print(stack.pop())  # 2 (LIFO)
from collections import deque
q = deque([1,2]); print(q.popleft())  # 1 (FIFO)
