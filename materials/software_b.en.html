Access control — Guard Clauses

The same function, rewritten with guard clauses: failure conditions are checked early and the function returns immediately, keeping the flow linear.

function checkAccess(user) {
  if (!user) return "deny";
  if (!user.active) return "deny";
  if (!user.paid) return "deny";
  return "access";
}

Each failure condition is handled separately and exits the function. There is no nested else, so the eye follows a straight line.

  • No nesting.
  • Each line has a single purpose.
  • The success path is visible at the end.
