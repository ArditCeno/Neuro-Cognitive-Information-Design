Informatikë - Mid - M3 — Kombinim: funksione + lista + kushte

  • Funksion që merr listë dhe kthen listë të filtruar
  • Dictionary: çelës→vlerë, d['a']=1
  • Numërim me dict: d[k]=d.get(k,0)+1
  • enumerate() jep (indeks, vlerë)
  • Testo me raste kufitare: listë bosh

Kod / formulë

def frekuenca(lst):
    d = {}
    for x in lst:
        d[x] = d.get(x, 0) + 1
    return d
print(frekuenca([1,2,2,3,3,3]))  # {1:1,2:2,3:3}
