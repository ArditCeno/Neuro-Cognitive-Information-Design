Access control — checkAccess()

The following function decides whether a user may enter the admin panel. The conditions check existence, active status, and payment status.

function checkAccess(user) {
  if (user) {
    if (user.active) {
      if (user.paid) {
        return "access";
      }
      return "deny";
    }
    return "deny";
  }
  return "deny";
}

The function always returns a string: "access" or "deny". Note that all conditions are checked in sequence, one nested inside another.

The inner if block checks both user.active and user.paid together. Access is granted only when all three conditions are true: the user exists, is active, and has paid.

If the user is not active, the function returns "deny" immediately, regardless of payment status.
