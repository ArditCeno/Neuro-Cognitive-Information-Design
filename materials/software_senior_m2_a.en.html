  • A stack is LIFO
  • A queue is FIFO
  • Set lookup is O(1) on average
  • Balanced brackets are checked with a stack
  • A binary tree node has at most 2 children
  • BFS uses a queue
stack = []
stack.append(1); stack.append(2)
print(stack.pop())  # 2 (LIFO)
from collections import deque
q = deque([1,2]); print(q.popleft())  # 1 (FIFO)
